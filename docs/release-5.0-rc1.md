**Soul Lantern（灵魂灯笼）5.0 的第一个测试版！本版本加入了全新的 AI 模式——用大白话描述想要的效果，就能生成可以直接用的 Minecraft 指令；同时上线账号体系和模板社区「万灯集」，并把整个界面换成了液态玻璃风格。这是改名以来改动最大的一次更新，欢迎大家先来试用、多提意见。**

### 测试版须知
- 这是测试版：账号、灵魂币和万灯集里的作品**可能会在正式版之前清空**。
- 测试期间**暂不开放充值和激活码**。灵魂币的来源：注册赠送、反馈奖励、加入贡献者计划。
- 「使用自己的 API key」是测试期间的临时功能，**正式版会关闭**。
- 安装包没有数字签名，Windows 可能弹出「Windows 已保护你的电脑」：点「更多信息」→「仍要运行」即可。
- 安装包内部的版本号显示为 5.0.0，这是正常的（Windows 安装包只认纯数字版本号）。
- 4.x 老版本将无法连接新服务器，请安装本版本。
- 遇到问题欢迎反馈（软件里「设置 → 反馈问题」）：[GitHub Issues](https://github.com/ReQiao/soul-lantern/issues)（推荐），或 [B 站私信](https://space.bilibili.com/3690984732887987/)（没有加速器时用）。每一条有效反馈都会获赠测试用的灵魂币，记得附上用户名。

### 新增的功能
新增 AI 模式：用大白话描述想要的效果（比如「做一把能射 TNT 的弓」），自动生成指令并给出思路说明；需要持续生效的效果会单独列出，可一键部署到存档
新增 AI 多轮对话：可以在上一次的结果上继续追问修改（比如「改成用箭」），不用把需求重说一遍
新增多个 AI 模型可选：qwen3.7-plus、qwen3.8-flash、qwen-long-latest、deepseek-v4.1-flash、glm-5.3，按真实用量扣灵魂币，生成前会先按所选模型预估这次最多花多少
新增账号体系：手机号注册、登录、找回密码、修改密码和用户名；余额跟着账号走，换电脑、重装系统都不丢
新增模板社区「万灯集」：发布自己的手动模板或 AI 提示词，浏览、点赞、收藏、评论别人的作品，一键载入使用；不合适的内容可以举报
新增模板库：内置模板和在万灯集里收藏的模板放在一起，随时调用
新增一键部署到存档：手动选择存档、手动模式和 AI 模式都能部署，循环效果自动挂到数据包的 tick 上，并会识别存档的实际版本，和当前选择不一致时给出提示
新增手动模式撤销 / 重做 / 重置（Ctrl+Z / Ctrl+Y）
新增 custom_data 组件支持，AI 生成的特殊物品（比如爆炸箭）只对自己生效
新增液态玻璃界面：背景灯笼与光晕、开场动画、弹窗从按钮位置展开，可以用「玻璃透明度」滑杆调节通透程度
新增设置页：贡献者计划、反馈入口（可一键复制诊断信息）、版本信息
新增贡献者计划：自愿上报使用数据帮助改进软件，可获得灵魂币奖励，随时可以在设置里退出
新增「有新版本」提示：发布新版本后，软件顶部会提示并可一键打开下载页
新增 F11 全屏
新增「使用自己的 API key」（仅测试版）：支持 OpenAI 格式的接口（OpenAI、DeepSeek、通义千问、各种中转），key 加密保存在本机，不经过我们的服务器，不消耗灵魂币
新增简体中文安装包：安装时可以选择只为自己安装还是为所有用户安装；电脑缺少 WebView2 组件时会提示并自动安装

### 优化
优化 AI 生成的可靠性：拦截 AI 编造的物品 / 方块 / 实体 / 附魔 / 效果 id，并按所选游戏版本校验
优化模板文件格式：加入格式版本号，以后用新版本保存的模板在旧版本里打开会给出明确提示，不会读坏
优化界面性能：常驻的大面板不再使用实时模糊，打字时从约 8fps 恢复到约 63fps
优化安全性：大模型的 key 只保存在服务器上，不再打包进安装包；客户端与服务器之间使用证书锁定（附带离线备用证书）；收紧内容安全策略（CSP）
优化一键部署：数据包命名空间改为 soul_lantern，每次部署前先整包清空，不会残留旧的循环效果
许可证由 GPLv3 改为 AGPL-3.0-or-later，使用须知同步更新
修复依赖链上 nanoid 的高危漏洞

### 修复的问题
修复基岩版物品 ID 使用了 Java 版 ID 表的问题，补齐 Java 版缺失的两个诅咒附魔
修复爆炸箭等特殊效果会误伤所有箭的问题
修复 AI 生成的血量、效果时长、朝向、粒子、判定实体、计分板等参数不可靠的问题
修复在手动模式和 AI 模式之间切换时整页跳动的问题
修复旧的一键部署重新部署时，之前的循环效果仍在运行的问题
修复窄屏下调高玻璃透明度后，要滚到屏幕外才能看见效果的问题
修复物品选择弹窗里物品名过长时一行显示不全的问题
修复万灯集和管理页内容贴着边框、标题看起来被窗口左边切掉一截的问题
